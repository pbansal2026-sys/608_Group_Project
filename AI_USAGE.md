# AI Usage
We acknowledge the use of [ChatGPT](https://chatgpt.com/), [GitHub Copilot](https://github.com/features/copilot), and [OpenAI Codex](https://openai.com/codex/) during the development of this project.

Generative AI was extensively used to assist with writing and refining the Python code for the Streamlit dashboard, including implementing interactive visualisations, user interface components, and dashboard functionality. The data-wrangling code was primarily written by the group members, with AI assistance used for debugging, identifying errors, and suggesting corrections.

The types of prompts used included requests to generate Streamlit and Plotly code based on specified requirements, troubleshoot Python errors, improve dashboard design and functionality, and explain or correct existing code.

AI-generated outputs were reviewed, tested, and modified by the group members to ensure that they aligned with the project's objectives and analytical requirements. The group members remain responsible for the final code, data processing, analysis, interpretation, and conclusions presented in this project.
